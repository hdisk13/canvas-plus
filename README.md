# Canvas Plus

An HTML5 canvas-based paper-doll / cutout animation tool for **Mystery Theater** (TacomaData).

## What it does

- Pre-load character cutout images
- Rig simple pivots and transforms
- Animate cutouts (bobbing, arm swings, walk cycles)
- Export frame sequences for the YouTube pipeline

Early scaffold. Tooling and UI will land in follow-up commits.
